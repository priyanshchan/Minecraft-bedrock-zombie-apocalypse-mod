# Weapon attachments: mounts and conventions

Generated by `tools/gen/content.py` from `tools/gen/held.py`. Every gun is built so attachments can be added later without touching its model.

## Bones

| Bone | What it holds |
| --- | --- |
| `item` | the hold transform per view (do not put boxes here) |
| `gun` | the whole weapon; reload, jam and malfunction animations move it |
| `frame` | the fixed parts |
| `mag` > `def_mag` | the magazine; an extended magazine goes in `mag` next to `def_mag`, which it hides |
| `bolt`, `charging_handle`, `slide`, `pump`, `cover`, `rocket`, `shell` | moving parts (animated) |
| `att_optic` > `def_optic` | top rail: optics; `def_optic` is the iron sights or factory scope |
| `att_muzzle` > `def_muzzle` | muzzle thread: suppressors, compensators; `def_muzzle` is the flash hider |
| `att_underbarrel` > `def_underbarrel` | under rail: grips, bipods, launchers |
| `att_side` | side rail: lasers, lights |
| `att_stock` > `def_stock` | stock |

Each `att_*` bone pivots at its mount point and carries a locator of the same name. Positions below are in the gun's own frame and units (quarter pixels): `f` forward along the barrel, `u` up, `s` to the gun's left; `length` is the usable rail length.

## Adding an attachment later

1. Model it in `tools/gen/held.py` as a function that adds boxes to a gun's `att_<slot>` bone (e.g. `def red_dot(g)` using `g.use("att_optic")`), and call it for every gun whose slot fits.
2. Show it only when fitted: give each attachment a `part_visibility` entry in `controller.render.frontline.gun`, and hide the matching `def_<slot>` part when it is on. The condition reads the holder's fitted attachments from an entity property the scripts set (`frontline:att_<slot>`, needs a `player.json` with those properties).
3. Add the attachment item and register it in `behavior_pack/scripts/attachments.js` (`registerAttachment`) with its slot, the guns it fits and its stat changes (spread, recoil, range, damage, magazine size, reload time, loudness).
4. The scripts already store fitted attachments on the gun item (`fl:att`) and apply every attachment's stat changes when the gun fires and reloads.
